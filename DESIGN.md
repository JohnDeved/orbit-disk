# Orbit Disk design

Direction: the user's DaisyDisk reference, translated into our own native storage explorer. The disk map carries the interface's visual identity. The user-approved Night app icon pairs a coral disc and ivory orbital ring with a charcoal tile; the application header is reserved for location and actions.

Design read: a native disk-space analysis app for Mac users, with a restrained dark canvas and a prominent circular data visualization. ENERGY 2 / RHYTHM 2 / MOTION 1.

- Charcoal surfaces keep bright categorical sectors distinct across adjacent tree levels and leave small files legible.
- Coral marks the scan/collection actions; the multi-hue chart palette encodes separate filesystem branches and is repeated in the content list.
- A fixed places column, flexible map, and file inspector mirror the sequence choose, inspect, review.
- System typography follows native Mac conventions; monospaced digits keep size comparisons stable.
- Interface copy names locations, actions and state directly. The empty screen has one scan instruction; the empty header has no tagline. Repeated encouragement and reassurance are omitted. Deletion consequences, incomplete sizes and actionable errors remain explicit.
- Wide space around the map separates exploration from the denser file rows.
- The native unified title bar aligns the current location, search, refresh and folder picker with the system window buttons. The header contains no logo or wordmark. Sidebar and canvas colors continue behind the transparent title bar, including the sidebar divider. Toolbar content fits inside the native title bar instead of extending above its edge. Bounded control widths keep navigation from shifting the toolbar; long locations truncate.
- Map folders open on a single click, and the whole center circle goes up. File rows retain native selection and double-click behavior, with a separate arrow button for direct folder navigation. Going up keeps the previous folder selected.
- Dragging starts after a small movement threshold so clicks still navigate. The initial sector remains the drag source when crossing other rings. The collection footer is unboxed at rest. A fixed 12-point gap separates it from the index status above. During a drag, its full drop area gains a dashed coral outline, then a solid target with “Release to collect”; Escape cancels. Group sectors retain their actual members, and large groups validate in the background.
- Map hover highlights the related Contents row and scrolls it into view; outer-ring paths appear above the list. Row hover highlights the corresponding map segment. Selection remains independent so action buttons do not change targets while the pointer moves toward them.
- Selected rows use a solid warm fill and a thick coral inset outline. Hovered rows use a neutral fill and a thin slate outline, separating the persistent action target from temporary pointer feedback. The native list retains keyboard and accessibility selection; only its default blue selection paint is suppressed within this list.
- While the list scrolls, row-hover feedback is suppressed through wheel input, live scrolling and trackpad momentum. Selection stays visible; hover resumes at the actual row under the pointer after the list settles.
- File rows and search results can be dragged directly into the collection tray. The pressed row stays the source while crossing other rows, with the same movement threshold, private payload and cancellation behavior as map dragging. The separate folder arrow remains an immediate navigation control.
- Refresh, Finder, Preview/Open, collection review, and removal have visible labels. The main collection action fills the inspector width; folder arrows have a 32 × 36 target. The tray remains available across navigation.
- Collection state stays visible independently of hover and selection: collected sectors retain their branch color under dark diagonal hatching and a check badge. A minus badge marks partially collected ancestors or groups; it does not imply the whole folder is staged. The file list uses matching text and symbols. Tiny included sectors retain hatching even when a badge cannot fit. Coverage is cached when the collection changes and never queries the filesystem during drawing.
- Collection review keeps Trash as the prominent action and offers permanent deletion separately. Permanent deletion opens a second sheet with the full paths, folder-content scope, and an explicit irreversible-action warning. The destructive action has no default Return shortcut; Escape cancels. Both choices lock collection editing while removal runs.
- Clicking the app background outside a dialog dismisses only the top dialog, matching its Cancel or Done action. The click is consumed so underlying controls stay inactive. Collection review remains locked while removal runs; pending errors wait until an open preview or details sheet closes.
- Enabled actions and interactive map regions use the native pointing hand. Disabled controls, map gaps, and the noninteractive root center retain the default cursor. A single map hover position is evaluated against the current folder's geometry.
- The circular motif represents a hierarchy of bytes, not decoration. Arc angles use actual scanned sizes.
- SF Symbols identify real filesystem actions and locations. The Night app icon carries the orbit motif into Finder and the Dock, using the interface's charcoal/coral palette. Exact circle/ellipse geometry, centered bounds and transparent margins preserve its silhouette across icon sizes; restrained satin texture, bevels and contact shading distinguish its surfaces.
- Rounded corners group the file inspector and inputs; navigation and file rows stay flat.
- Motion is limited to hover and native feedback, so folder changes do not distract from reading sizes.
- Hover uses a white sector outline without dimming other branches, so crossing gaps cannot flash the graph colors. The colored map and collection marks retain their drawing layer; hover and selection update a separate outline layer.
- Pointer feedback reuses prepared chart geometry, exact hit-test paths and item lookups. Collection changes update the marks; a newly published folder rebuilds the map. This keeps interaction work separate from reading and arranging the filesystem data.
- First-scan browsing begins with discovered folders and measured files. Waiting folders have an explicit label and no invented chart area; unfinished totals say so far. A compact footer reports ongoing work while keeping the explorer available.
- Partial updates preserve the current folder and selected path. Colors retain their assigned branch ordinals while that folder is visible. Mouse-down holds the latest update until the gesture ends, preventing moving targets during clicks and collection drags.
- Discovered files and folders can be collected during mapping. The inspector says “Add to Collection”; the selected item's eligibility and any active collection operation determine whether the button is enabled. Stopping keeps the partial map visible with a Restart Mapping action.
- Header actions, breadcrumbs, metrics, inspector actions, mapping status and collection tray keep reserved dimensions as their contents change. The inspector shows disabled actions before selection so selecting a file does not shrink the list. A fixed device area keeps Places steady when volume metadata arrives.
- File rows retain the same height and size/action columns in browsing, search and collection states. The collection marker and search path share the secondary line. The native scrollbar gutter remains present for short lists; the system scrollbar style is retained.
- The map center reserves name, size, detail and Up slots. Smaller windows use compact text and an Up chevron. Names truncate within their regions; the file path remains available in the inspector and row help. Data-driven sectors and hover-driven list scrolling still reflect the current files.
- Collection errors replace text inside a reserved header region, preserving the list and action positions. Quick Look uses a fixed window and single-line title so media size and filename length cannot resize the dialog.
- The native macOS app has a minimum window size of 1060 × 680. A mobile layout is outside this desktop application's scope.

A first scan creates a saved local index. Reopening a location reads the visible folder; background filesystem events update changed folders. The opening state gives way to a usable explorer as soon as the first preview is available. Refresh keeps an existing complete chart, navigation, and collection available, with status and a Pause action in the footer. Saved/indexed timestamps distinguish cached data from active mapping. Search reads the whole saved index. Empty, waiting, mapping, stopped, partial, error, no-result, selected, and collection states have visible text.

Updates use the native app menu, Settings window, and Sparkle dialogs, keeping the explorer layout unchanged. The English notice says “Update Orbit Disk” and gives the available and installed versions once. “Update” starts the download; “Update and Restart” names the final action. “Skip This Version” retains its distinct meaning. A checked-in localization overlay applies before bundle signing, with no custom window or runtime replacement of Sparkle behavior. Settings explains the daily check, manual restart, and loss of the current unsaved collection. Native controls retain platform focus, keyboard and accessibility behavior.
