[Download for Mac](https://github.com/JohnDeved/orbit-disk/releases/download/v0.11.0/Orbit-Disk.dmg). Open the disk image and drag Orbit Disk.app to Applications, or use **Orbit Disk → Check for Updates…**.

Orbit Disk 0.11.0 keeps large maps up to date much faster. Refresh now reads only what changed, a full rescan writes only what differs from the saved map, and indexing of very large folders keeps pace with discovery. It also fixes several errors that could interrupt mapping, and redesigns the status footer.

## Refresh reads only what changed

- **Refresh (⌘R)** uses the change history instead of reading everything again. It continues an unfinished map, picks up every change made while monitoring was paused, and re-lists folders that were unreadable before if they can now be read (for example after granting Full Disk Access). On a whole-Mac map with 6.6 million files, Refresh came back up to date in 7–12 seconds, where it used to start a 50–60 second rescan.
- **Rescan Everything (⌥⌘R)** reads the whole location again. It is in the File menu, and you can also ⌥-click the toolbar's Refresh button.
- A changed file now re-reads only its own folder, not every folder below it. Deleting a large folder such as `node_modules` updates its parent instead of starting a full rescan. Changes inside folders that the map could not read no longer re-read all of `~/Library` or your Home.
- Mounting or ejecting another disk, disk image or simulator runtime no longer discards the change history of a whole-Mac map.

## Faster rescans and indexing

- A full rescan starts from a copy of the saved map. Folders that did not change cost almost nothing to write. Rescanning a 5-million-file Home took 31–34 seconds, against 50–55 seconds without the copy.
- Indexing writes in larger transactions and keeps far more of the index in memory. Mapping the same Home from scratch took 47–75 seconds, against 133–157 seconds in 0.10.0. On a generated 600,000-file tree, mapping took 4–5 seconds instead of 17.
- When the change history covers the scan, folders are no longer checked a second time while being written. That second check re-read about 5 million folders from disk.

These are warm runs on one Mac, with other applications running. They do not measure cold-disk behavior.

## Fixes

- "Interrupted system call (os error 4)" no longer stops a mapping. Interrupted filesystem calls are retried.
- "Resource deadlock avoided" no longer appears during a refresh. Refreshes skip iCloud Drive and other cloud storage folders, as the first mapping already did.
- Opening a folder right after a background update no longer fails with "the saved map changed; refresh and try again".
- **Clear Cache** shows its confirmation again.
- A failed background update shows its reason in the footer instead of an alert. Only errors from a removal you started still show an alert.

## Interface

- The status footer is redesigned. It shows mapping progress, background updates and their errors in one consistent line, with the action you need next.
- The sidebar's device card shows the disk's total capacity next to the available space.
- The AI integration's refresh tool takes an optional `everything` flag for a full rescan.

## What changes when you update

Saved maps, Places and Full Disk Access are kept. The map format is unchanged, so nothing is rebuilt.
