[Download for Mac](https://github.com/JohnDeved/orbit-disk/releases/download/v0.9.13/Orbit-Disk.dmg). Open the disk image and drag Orbit Disk.app to Applications, or use **Orbit Disk → Check for Updates…**.

Orbit Disk 0.9.13 fixes Macintosh HD mapping that could omit user folders and applications, and makes discovery and indexing progress easier to read.

## Whole-drive mapping

- Macintosh HD now includes the boot System and Data volumes through the normal `/` folders, including Users, Applications and Library. Verified macOS aliases are counted once; other mounted volumes remain separate.
- Native directory metadata is reconciled with the identity returned when a macOS firmlink is opened. Secure traversal still rejects replaced directories and unrelated mounts.
- Existing whole-drive maps update for the expanded coverage without clearing Places caches. Newly discovered folders remain visible during that update.
- Opening Home or Documents inside an active drive map reuses that mapping. A whole-drive scan can also import a completed folder cache after a bounded check for filesystem changes. Separate unfinished child scans are not merged into a new parent, and imported records remain in the parent's own cache.
- Cloud-storage exclusions, removal safeguards and interrupted-mapping recovery remain in place.

## Mapping progress

- A shared bar shows files found in memory and the share indexed in the local cache, with separate live counts. It does not estimate an unknown total for the whole folder.
- Finished maps transition to **Indexed · updated … ago**. The progress area keeps the same height through mapping, updates and completion.
- Progress stays with its mapping session when navigating or switching Places. Visible files remain available while discovery and indexing continue.
- File-size details align toward the center divider for easier comparison.

## Maintenance and verification

- Check scripts are grouped under `scripts/checks/`, with CI and contributor commands updated. README screenshots are regenerated only by the release workflow.
- Native regression checks cover boot-volume traversal and totals, cache reuse and event history, old-map upgrades, cloud exclusions, asynchronous discovery, removal and crash recovery. The installed app was also checked while switching between Macintosh HD and Home.

This release does not claim a new indexing-throughput improvement. Work on the durable indexing bottleneck follows separately.
