Orbit Disk 0.9.11 adds AI tools and a command-line client that use the running app’s maps, search and collection. Cloud storage is now excluded from mapping and collection by default.

## Connect an AI client

Choose **Orbit Disk → AI Integration… → Connect to Codex** once. New Codex sessions discover Orbit Disk’s tools automatically. Other MCP clients can use **Copy MCP Settings**. The bundled server starts the app when a tool needs it; Orbit Disk does not require an AI API key.

- Inspect mapping progress, list files, search names, navigate folders and build a collection while discovery continues. Tool results identify incomplete sizes and truncated search results.
- Prepare a removal plan with the exact items and Trash or permanent-deletion mode. Execution requires user authorization and a single-use token that expires after five minutes. Changed maps or collections invalidate the plan; the removal pipeline rechecks file identities before changing files.
- Follow a removal’s result after switching maps. A lost connection reports when the outcome is uncertain so the client can check state before attempting another action.
- Use typed errors and published input/output schemas. Failed searches can be retried with the same query. The MCP server validates request IDs, initialization and unsupported execution options.
- Install `orbitdisk` in `~/.local/bin` from the integration menu. The JSON client supports the same actions, plus tool discovery and `--version`. Setup preserves unrelated command-line files and client configuration.

The interface uses a private local socket and returns file metadata. Connected AI clients handle that metadata according to their own settings. [Setup and protocol details](https://github.com/JohnDeved/orbit-disk/blob/v0.9.11/docs/AI-INTEGRATION.md).

## Cloud storage exclusions

Mapping and collection skip the standard macOS CloudStorage and iCloud Drive locations, plus Desktop and Documents when macOS identifies them as iCloud-backed. Discovery disables automatic downloads of cloud-only content. The native app and AI tools use the same rules.

Older saved maps are rebuilt once to apply these exclusions. Custom sync locations outside the standard roots may not be identifiable; Orbit Disk does not guess based on arbitrary folder names.

## Responsiveness and fixes

- The blocking mapping loop and file removal run outside Swift’s cooperative task executor, allowing other tasks to proceed when those operations block. Regression checks verify that these operations run outside a Swift task while preserving map switching, deletion completion and reconciliation. A separate local experiment reproduced the stalled switch with two cooperative workers available and passed after the fix.
- The AI setup window has shorter instructions and closes when clicked outside.
- README screenshot validation samples more densely, avoiding false blank-image failures for views with few items. Screenshots still update only on releases.
- Durable staging checks follow the current index format instead of asserting the previous version.

The release workflow runs the Linux checks and macOS regression suites before publishing the universal app and signed update feed. No new scan-throughput measurements are claimed for this release.
