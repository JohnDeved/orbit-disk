Orbit Disk 1.0.0 is a complete rewrite in Rust with the GPUI framework. The map, collection, removal review, search, saved maps and AI tools work as before. Mapping and indexing are faster, the interface draws on the GPU, and the code is ready for future Windows and Linux versions.

## Faster mapping and indexing

The scanner, saved-map index and live inventory are new. In alternating comparisons against 0.9.15 on the same machine and fixtures:

| Workload | 0.9.15 | 1.0.0 |
|---|---:|---:|
| Mapping 20,000 real files in 2,000 folders | 0.311 s | 0.134 s — **2.32× faster** |
| Indexing 100,000 discovered files in 10,000 folders | 1.132 s | 0.627 s — **1.81× faster** |
| Indexing 1,000,000 discovered files in one folder | 6.769 s | 3.873 s — **1.75× faster** |
| Indexing 10,000 empty folders | 0.359 s | 0.125 s — **2.87× faster** |
| Finding 90,000 files in 3,662 nested folders | 266 ms | 199 ms — **1.34× faster** |

Times include publication of the completed index. Peak write-ahead journal size is similar (within about 10%, lower for many small folders), and saved maps are about 10–15% smaller. Other work was running on the test machine, so absolute times vary; each comparison alternated both versions under the same conditions.

## Smoother interface

- The map draws its rings with exact anti-aliasing at your display's resolution, so edges and the gaps between segments stay sharp.
- On the test machine, hovering, scrolling, opening folders and dragging stayed well within a 120 Hz frame (99th percentile 6.2 ms between frames, while the machine was under load).
- The Contents list scrolls smoothly through folders with a million items. Hovering the map reveals the related row without delay.
- Busy folders cost less in the background. Changes inside the folder you are viewing appear within about 2 seconds. Changes elsewhere are batched, and a refresh that finds nothing new leaves the saved map alone.

## What changes when you update

- **Your maps are rebuilt.** 1.0.0 uses a new, faster index format. Maps saved by earlier versions are removed on first launch, and each location is mapped again the first time you open it. Places and the last opened location are kept.
- **Full Disk Access must be granted again.** macOS treats the new app as a different program. If you used Full Disk Access, turn it on again for Orbit Disk in **System Settings → Privacy & Security → Full Disk Access**.
- **Interrupted removals are still recovered.** The removal journal is carried over and upgraded. Earlier versions cannot read it after the upgrade.
- **AI tools keep working.** Existing Codex connections use the same command-line tool inside the app.
- **Quick Look** is replaced by opening the item in its default app. Space and **Preview** do the same.

## Safety

Removal keeps the safeguards of earlier versions:
- Trash is the prominent action. Permanent deletion needs its own confirmation, with full paths and no default Return key.
- Every item's identity and parent folder are checked again just before removal.
- Symbolic links are never followed when deleting folders.
- Each removal is recorded before any file is touched, so an interrupted removal is reconciled on the next launch.
