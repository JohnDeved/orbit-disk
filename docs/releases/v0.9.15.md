[Download for Mac](https://github.com/JohnDeved/orbit-disk/releases/download/v0.9.15/Orbit-Disk.dmg). Open the disk image and drag Orbit Disk.app to Applications, or use **Orbit Disk → Check for Updates…**.

Orbit Disk 0.9.15 speeds up durable indexing while keeping discovered files available before the cache catches up. It includes the indexing improvements developed after 0.9.14.

## Faster indexing

- Ready small folders share bounded database transactions, reducing per-folder write overhead. The writer does not wait for a batch to fill, and discovery continues independently.
- SQL statements are reused within each group instead of being prepared again for every folder.
- New files use a smaller database insert after their names are checked. Completing a folder skips redundant cleanup when no old entries need removing.
- Full refresh marking advances through the directory queue without repeatedly reading the completed prefix. Listings are accepted in the correct generation, avoiding a second discovery pass over the same directories.
- SQLite statements release their read results before commit, allowing the writer to checkpoint its journal. A measured 16,384-page checkpoint interval avoids the single-large-folder regression seen with more frequent checkpoints.

In alternating local tests against 0.9.14:

| Workload | 0.9.14 | 0.9.15 |
|---|---:|---:|
| Mapping 20,000 real files in 2,000 folders | 0.767 s | 0.335 s — **2.29× faster** |
| Indexing 100,000 discovered files in 10,000 folders | 3.143 s | 1.013 s — **3.10× faster** |
| Same inventory after a refresh generation change | 5.459 s | 1.043 s — **5.23× faster** |
| Indexing 1,000,000 discovered files in one folder | 6.636 s | 5.560 s — **16% less time** |

Times include publication of the completed index. Sampled peak write-ahead journal size fell from about 1.4 GiB to 59–64 MiB on the large indexing fixtures. A deletion-heavy refresh control showed no regression.

## Recovery and responsiveness

- Each committed batch still uses SQLite FULL synchronization and records its recoverable progress atomically. Cancellation, deletion reconciliation and interrupted-process recovery retain their existing safeguards.
- Existing cached maps remain usable. This release does not require clearing the cache or migrating its format.
- Visible files remain available for browsing, collection and deletion while indexing continues.

[Benchmark methodology and raw evidence](https://github.com/JohnDeved/orbit-disk/blob/v0.9.15/docs/benchmarks/fresh-file-indexing.md) describe the generated fixtures, repeated comparisons and measurement limits. These tests do not establish cold-disk or whole-Mac throughput. Active readers can still make the journal exceed its checkpoint interval.
