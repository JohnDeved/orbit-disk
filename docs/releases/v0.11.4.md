[Download for Mac](https://github.com/JohnDeved/orbit-disk/releases/download/v0.11.4/Orbit-Disk.dmg). Open the disk image and drag Orbit Disk.app to Applications, or use **Orbit Disk → Check for Updates…**.

Orbit Disk 0.11.4 finds the files on a whole drive more than twice as fast. On an Apple M5 with 5.1 million files, every file was found in 18.5–21 seconds instead of 42–45, and the map was saved after 32–37 seconds instead of 50–51. Method and raw output: [whole-drive benchmark](https://github.com/JohnDeved/orbit-disk/blob/v0.11.4/docs/benchmarks/whole-drive.md).

## Faster mapping

- Eight folders are read at the same time instead of four. On an SSD that nearly halves the time to find every file.
- A new map builds its size indexes once, when it is saved, instead of updating them for every folder.
- Saving checks the mapped folder once per batch instead of before every folder.

## Memory

Mapping now finds files faster than it can save them, so found files wait in memory for a moment. On the 5.1-million-file Mac, the scan peaked at about 1.6–1.7 GB, compared with about 0.8 GB before; waiting files are freed as they are saved. Mapping slows down rather than holding more than 1 GB of waiting files, so very large drives stay bounded.

## What changes when you update

Saved maps, Places and Full Disk Access are kept. The map format is unchanged.
